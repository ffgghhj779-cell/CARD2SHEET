# 📇 CARD2SHEET — Exhibition Business Card & Lead Scanner Bot + Web App

منظومة متكاملة لمسح كروت الأعمال وبادجات المعارض والبروشورات بالذكاء الاصطناعي (**OpenAI GPT-4o Vision + Whisper-1**)، مع تصنيف تلقائي للقطاعات، دعم البصمات الصوتية والرسائل النصية، ذاكرة ذكية، مزامنة لحظية مع **Google Sheets**، وتصدير ملفات **Excel (`.xlsx`)**.

---

## ✨ المميزات الرئيسية

1. **استخراج فائق الدقة ثنائي اللغة (عربي / إنجليزي):**
   - فصل الاسم العربي (`full_name_ar`) عن الاسم الإنجليزي (`full_name_en`) دون ترجمة أو تأليف.
   - قراءة الكروت المقلوبة (90° / 180° / 270°) أو المائلة أو التي بها لمعان فلاش وظلال.
2. **دعم الكروت المتعددة والبادجات في صورة واحدة:**
   - اكتشاف كل كرت أو بادج معرض (`Exhibition Badge`) على الطاولة وتسجيله كصف مستقل.
   - دمج ذكي (`Smart Merge`) عند مسح نفس الكرت مرتين دون تكرار الصفوف.
3. **البصمات الصوتية (`Voice Notes`) والملاحظات النصية (`Captions`):**
   - تفريغ التسجيلات الصوتية بالعربي والإنجليزي عبر **OpenAI Whisper (`whisper-1`)** وإضافتها تلقائياً لخانة الملاحظات في قاعدة البيانات وفي Google Sheets.
4. **ذكاء محادثي وذاكرة ممتدة:**
   - **إضافة عميل من نص حر:** إرسال بيانات عميل كنص يسجله فوراً كعميل جديد.
   - **تعديل البيانات بالرد (`Reply`):** عمل Reply على رسالة أي عميل لتصحيح الإيميل أو الهاتف أو القطاع في الشيت مباشرة.
   - **بحث باللغة الطبيعية:** السؤال مثلاً *"مين كان من شركة سدرة؟"* أو استخدام `/find`.
   - **توجيه ذكي داخل الدفعات:** عند تصوير عدة كروت معاً وذكر اسم شخص محدد في الملاحظة، تُربط الملاحظة بكرته فقط.
5. **قاعدة بيانات محلية (`SQLite`) + مزامنة لحظية مع `Google Sheets` + تصدير `Excel`:**
   - حفظ محلي فوري يعمل حتى في حال انقطاع الإنترنت في المعرض، مع أمر `/sync` للمزامنة اللاحقة وأمر `/export` لتوليد ملف `.xlsx` منسق بالكامل.

## 🗂 هيكل المشروع

* **`app/` و `lib/`** — تطبيق **Next.js 15** كامل (واجهة ويب للموبايل + API + بوت تيليجرام مدمج يعمل تلقائياً عبر `instrumentation.ts`).
* **`tests/`** — منظومة اختبارات شاملة (`run-deep-tests.ts` + مولد كروت اختبارية `make-fixtures.mjs`) تغطي 15 سيناريو حقيقي.
* **`python-bot/`** — نسخة بايثون المستقلة لبوت التيليجرام (`python-telegram-bot` + `openai` + `gspread` + `openpyxl`).

## 🚀 التشغيل السريع (Node.js — Web App + Telegram Bot)

```bash
npm install
cp .env.example .env.local
# ضع مفاتيحك في .env.local وملف service_account.json في جذر المشروع
npm run dev
```

للإنتاج:
```bash
npm run build
npm start -- -p 3050
```

## 🧪 تشغيل الاختبارات الشاملة (Deep E2E Tests)

```bash
node tests/make-fixtures.mjs
node --import ./tests/loader.mjs tests/run-deep-tests.ts
```

## 🤖 أوامر بوت التيليجرام

* `/start` أو `/help` — عرض دليل الاستخدام
* `/export` — تحميل قاعدة البيانات كملف Excel (`.xlsx`)
* `/last` — عرض آخر عملاء تم مسحهم
* `/find <كلمة>` — بحث في العملاء المسجلين
* `/undo` — حذف آخر عملية مسح من القاعدة ومن Google Sheets
* `/stats` — إحصائيات العملاء حسب القطاع
* `/sync` — مزامنة أي سجلات معلقة مع Google Sheets
